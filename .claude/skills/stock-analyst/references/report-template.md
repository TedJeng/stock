# Artifact 報告模板（產業聚焦版）

報告是繁體中文 HTML，經 Artifact 工具發布。發布前先載入 `artifact-design` skill；有圖表時遵循 `dataviz` skill。favicon 用 `📈` 並保持穩定。

## 硬性限制

- **CSP**：不能外連任何資源。數據寫死在 HTML 裡，圖表用內嵌 SVG 或純 CSS。
- **主題**：亮/暗色都要支援（`prefers-color-scheme` + `:root[data-theme]` 覆寫）。
- **響應式**：寬表格包 `overflow-x: auto`，頁面不可橫向捲動。

## 章節結構（依序）

### 1. 市場概況
- 大盤與產業位置：SPY、SOX 指數（或 SMH 代理）近期表現
- AI 資本支出大趨勢是否仍成立（hyperscaler capex 指引，serenity 步驟一）
- **機構輪動相位一行**：Phase 1 記憶體 → Phase 2 光模組 → Phase 3 矽光子，目前市場在哪、對本期選股的含義
- 報告日期與數據時間戳

### 2. 高風險高報酬 Top 5
每檔卡片固定包含：

- Ticker、公司名、現價、市值、所屬供應鏈層級
- **卡點層級標籤**（與信心徽章並列）：`層級 · 卡點屬性`，例如「基礎材料層 · 核心卡點」「測試設備層 · 次級卡點」「GPU 層 · 非卡點」
- **推薦理由**（2–3 句，含輪動相位定位：這檔在 Phase 幾、該相位是否已定價）
- **四訊號驗證列**：量化 / 分析師 / 新聞 / 卡點，各自結論（✓ 正向、– 中性、✗ 反向）；用到「核心卡點升級中性訊號」加分規則時要標註
- **信心等級**：強（綠）/ 中（黃）/ 弱（灰）
- **關鍵風險**（具體到這家公司；本宇宙必提的共通風險寫在類別開頭警語，不重複佔卡片空間）

類別開頭警語：本類標的與半導體景氣高度連動，系統性回檔時會齊跌；多為中小型股，流動性差、可能單日大幅跳空。

### 3. 穩定投資 Top 5（產業龍頭）
同卡片結構，但：

- **護城河欄**用卡點語言（如「EUV 微影獨供」「先進製程代工壟斷」「量測設備寡佔」）
- 多列：淨利率、EPS 成長；有股息者列股息率
- 卡點層級標籤照掛（龍頭多為「核心卡點」或「次級卡點」，這正是它們穩定的原因）

### 4. ETF 產業主題三層配置
表格：層（核心/主題衛星/避險）、建議比例、ETF、價格、費用率、選擇理由。

- 避險層（SGOV）**必須存在**且說明比例邏輯：單一產業組合無分散效果，避險層是唯一的緩衝
- 回檔期間避險比例上調，並在理由欄說明
- 衛星層依當期輪動相位挑選，說明為何選這些主題

### 5. 歷史推薦績效回顧
招牌章節，**不可省略**：

- 無紀錄：一句「首次執行，本次推薦開始納入追蹤」
- 有紀錄：
  - 總覽：各類別勝率（超額報酬 > 0 比例）、平均報酬 vs SPY 同期
  - 明細表：日期、ticker、類別、推薦價、現價、報酬率、SPY 同期、超額報酬、當時信心等級
  - **2026-07-19 當天同時存在兩批紀錄**：前段為改版前「全市場版本」（v1）、後段為改版後「產業聚焦版」（v2）首次執行，靠日期無法區分，須讀 `recommendations.json` 的 `version` 欄位分組。表中標註版本欄或分組呈現，照算不隱藏
  - 若本期有標的因剔除紀錄被替換，可在明細表或剔除紀錄段落引用該筆紀錄的 `replaces` 欄位交代前後承接關係
  - 虧損照列（紅色但不遮掩）；可加一句方法論反思

### 6. 延伸觀察（選用）
serenity 名單中美股買不到的標的（SIVE、IQE、台鏈等）：一小段列出 ticker、市場、卡點定位，註明「無美股報價，僅供研究追蹤」。

### 7. 免責聲明
固定文字（小字、次要色）：

> 本報告非投資建議，僅為基於公開資料（Finviz、公開新聞）的研究整理。卡點框架與覆蓋名單轉述自 Serenity (@aleabitoreddit) 公開發文之整理，未經驗證其歷史績效。本報告標的集中於 AI/半導體單一產業鏈，無分散效果；高風險類多為中小型股，流動性與波動風險高。Finviz 免費版數據可能延遲；歷史績效不代表未來表現。實際投資前請自行查證第一手資料（10-K/10-Q、法說會、SEC 備案）。

## 呈現慣例

- 漲跌：正=綠、負=紅，帶 +/− 號；數字欄 `tabular-nums`
- 卡點層級標籤與信心徽章是每張卡片的視覺錨點，樣式全報告一致，掃一眼可比較
- 每檔資訊密度一致
- 剔除紀錄（交叉驗證未過的候選）各類別末尾一小段，交代理由——這是準確率驗證的透明性要求
- 對話摘要（發布後）：三類 ticker 清單各一行 + 歷史勝率一句 + 免責一句，不超過十行
